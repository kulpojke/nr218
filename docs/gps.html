GPS

What is GPS?

More properly, what is GNSS?

  • GNSS stands for Global Navigation Satellite System.
  • It uses signals from satellites to determine a receiver’s location, elevation, and precise time.
  • GPS is the U.S. GNSS; other systems include Galileo, GLONASS, and BeiDou.

History of GNSS

  • 1957: Scientists tracked Sputnik using shifts in its radio signal, demonstrating that satellites could aid navigation.
  • 1960s: The U.S. Navy’s Transit system became the first operational satellite-navigation system.
  • 1973–1995: The United States developed GPS, launching its first satellite in 1978 and reaching full operational capability in 1995.
  • 2000: The United States ended Selective Availability, greatly improving civilian GPS accuracy.
  • Today: GPS operates alongside other GNSS constellations, including GLONASS, Galileo, and BeiDou.

Important Points

  • Global Navigation Satellite Systems (GNSS) is the general category comprising the following systems:
    • GPS: United States, first satellite launched in 1978
    • GLONASS: Russia/Soviet Union, first satellite launched in 1982
    • BeiDou: China, first satellite launched in 2000
    • Galileo: European Union, first test satellite launched in 2005
  • Signals from Satellites
    • Signals contain the position of the satellite, and the exact time sent
    • \(\ell = c t\)

If you know your distance from 3 points in 3D space, theoretically you know where you are,

\[ \begin{aligned} \sqrt{(x - x_1)^{2} + (y - y_1)^{2} + (z - z_1)^{2}} = c t_1\\ \sqrt{(x - x_2)^{2} + (y - y_2)^{2} + (z - z_2)^{2}} = c t_2\\ \sqrt{(x - x_3)^{2} + (y - y_3)^{2} + (z - z_3)^{2}} = c t_3 \end{aligned} \]

but there are sources of error …

Your the ground unit’s time is wrong, so you need at tleast 4 satellites to solve for distance error caused by clock error, b.

\[ \begin{aligned} \sqrt{(x - x_1)^{2} + (y - y_1)^{2} + (z - z_1)^{2}} = c t_1 + b\\ \sqrt{(x - x_2)^{2} + (y - y_2)^{2} + (z - z_2)^{2}} = c t_2 + b\\ \sqrt{(x - x_3)^{2} + (y - y_3)^{2} + (z - z_3)^{2}} = c t_3 + b\\ \sqrt{(x - x_4)^{2} + (y - y_4)^{2} + (z - z_4)^{2}} = c t_4 + b \end{aligned} \]

  • How does the satellite know where it is?
    • Ground stations!
  • How do the ground stations know where they are, what with the continents moving around and all?
    • Quasars!
    • Radio telescopes male a precise map of continental movement from qulsars
    • Ground stations are tied into that map
  • Other complexities:
    • Relativistic effects
    • Rotation of earth
    • Atmospheric effects
  • So GNSS units use many satellites to improve location
    • phones, ~ 3m
    • Precision units , cms
  • GPS signals are weak
    • transmitted at about 50 W
    • arrives at about \(10^{-16}\) W

  • For each drain, enter the following into the Google Form:

  • After the class has submitted data:
    • open the linked Google Sheet
    • download the sheet as a CSV
    • open QGIS
    • add the CSV as a delimited text layer
    • set X field = longitude and Y field = latitude
    • set the CRS to WGS84, EPSG:4326
